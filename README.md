# Prometheus Monitoring Lab

## Overview
A monitoring lab built using Prometheus and Alertmanager to monitor a Node.js application.

## Technologies
- Prometheus
- Alertmanager
- Node Exporter
- cAdvisor
- Node.js
- Slack Incoming Webhooks
- Linux

## Features
- Monitor system metrics
- Monitor Docker containers
- Monitor a custom Node.js application
- Alert rules
- Slack notifications
